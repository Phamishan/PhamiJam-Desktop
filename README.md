# PhamiJam - See The Sound Through Phami’s Eyes ✨

## Features:

```
🎵 - Stream music
👤 - Google integration
🆓 - Free
⛔ - No ads
📃 - Library
⬇️ - Offline downloads
🌗 - Dark mode
📱💻 - Cross-device
```
